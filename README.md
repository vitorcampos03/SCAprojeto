O SCA (Sistema de Controle de Armamento) é um projeto desenvolvido para representar uma plataforma de gestão e controle de armamentos voltada a instituições de segurança.

O sistema apresenta uma interface moderna e responsiva, com foco na organização, controle operacional e digitalização dos processos relacionados ao gerenciamento de equipamentos.

🚀 Funcionalidades apresentadas Gerenciamento de armamentos Controle e monitoramento de equipamentos Gestão de escalas de serviço Interface para diferentes instituições de segurança Layout responsivo e moderno 🛠️ Tecnologias utilizadas HTML5 CSS3 Bootstrap 5 JavaScript 🎯 Objetivo

O projeto tem como objetivo demonstrar a aplicação de tecnologias web na criação de uma solução de gerenciamento, com foco em usabilidade, organização e controle operacional.

Projeto desenvolvido para fins acadêmicos e de estudo em desenvolvimento web.
